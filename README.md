# SAHA Project Control Center

A lightweight portfolio dashboard for tracking the projects owned by ZOUACEDRIC.

## Current features
- Portfolio overview with project counts by status.
- Search and status filtering.
- Dedicated overview, all-projects, priorities and roadmap views.
- Add, edit and delete project records.
- Browser-local persistence using localStorage.
- Export the portfolio to JSON.
- Responsive desktop and mobile layout.

## Run locally
No build tools or backend are required. Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
This is a static site and can be deployed to GitHub Pages, Vercel, Netlify or any static hosting provider. No environment variables are required.

## Important data note
The starter portfolio is prefilled from previously discussed projects. Statuses and next actions are working planning notes, not live GitHub or hosting telemetry. Changes made in the dashboard are stored in that browser only. A future integration can connect GitHub and deployment providers for live status.
